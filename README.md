# AI_Skills

A comprehensive repository of reusable AI skills, prompts, workflows, and workspace instructions designed to augment AI agents with specific domain knowledge.

This repository serves as a localized knowledge base, allowing agents to execute complex, multi-step workflows accurately. The skills cover a broad range of domains including:
- **Frontend & UI:** React components, shadcn/ui, design guidelines.
- **Backend & Database:** Supabase & Postgres best practices.
- **Web3 & Blockchain:** Comprehensive Ethereum development knowledge (ETHSkills).
- **Tooling & IDE Setup:** Workspace scaffolding, coding style enforcement, and prompt enhancement.

## ETHSkills

The repository includes a complete mirror of ETHSkills, which provides real-time, production-grade knowledge on Ethereum development for AI agents. 

In case you need to view the live web version of ETHSkills, you can find it here:
[https://termo.ai/skills/ethskills](https://termo.ai/skills/ethskills)
