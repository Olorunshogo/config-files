description: "Anything deferred to V2 or a later phase gets written into docs/v2.md in the repo, not just mentioned in chat"
metadata:
  type: feedback
---

When a plan or implementation marks a feature or table as "V2", "deferred", or "later phase", write it into `docs/v2.md` in that repo in the same turn, with a short reason.
Create the file if it's missing.

**Why:** in the user's words: "anything you're adding to v2 should be a docs/v2.md so no one forgets."
Scope call-outs made only in chat get lost.
